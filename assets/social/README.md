# 소셜 로그인 브랜드 에셋

로그인 화면(`lib/screens/login_screen.dart`)의 간편 로그인 아이콘에 쓰는 에셋.

| 제공자 | 현재 적용 | 비고 |
|---|---|---|
| 구글 | `google.png` (4색 G) | 흰 원 배경 + 변형 없음 → **가이드라인 준수** |
| 카카오 | `kakao.png` (동그란 TALK 로고) | ⚠️ **가이드라인 비준수** (아래 참고) — 디자인 우선 결정 |
| 네이버 | (에셋 없음) | `simple_icons`의 N 글리프 직접 사용 — 익숙한 마크라 그대로 유지 |

## ⚠️ 카카오 — 출시 전 반드시 확인

[카카오싱크 디자인 가이드](https://developers.kakao.com/docs/ko/kakaosync/design-guide)는
다음을 **금지**한다:

- 심볼(말풍선) 형태·비율·색상·방향 변경
- 심볼 단독 사용 / 레이블 없는 버튼 구성
- 카카오톡 앱 아이콘형 로고를 로그인 버튼에 사용

현재 적용된 `kakao.png`(노란 원 + TALK)는 위에 해당하므로 **카카오 검수에서
지적될 수 있음**. 정식 출시 전 [도구] > [리소스 다운로드] > [카카오싱크] >
[로그인] 의 공식 "카카오 로그인" 레이블 버튼으로 교체할 것.
규정 색상: 컨테이너 `#FEE500` / 심볼 `#000000 90%` / 레이블 `#191919`.

## 구글

[Google Identity 브랜딩 가이드](https://developers.google.com/identity/branding-guidelines)
기준 — 4색 G를 흰 배경에 변형 없이. 색 변경·회전·왜곡 금지.

## 교체 방법

이 폴더에 같은 파일명(`google.png`, `kakao.png`)으로 덮어쓰면 코드 수정 없이
자동 적용. 파일이 없으면 `simple_icons` 글리프로 임시 대체된다.
